# Актерская Барселона

Статический сайт проекта на Astro. Курсы и педагоги хранятся как типизированные данные, страницы собираются из общих компонентов, а GitHub — единственный источник кода для Vercel.

## Локальный запуск

Требуется Node.js 24+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Основные проверки:

```bash
pnpm format:check
pnpm build
pnpm lint
pnpm test:e2e
```

Полный набор выполняется командой `pnpm ci` и автоматически запускается в GitHub Actions.

## Как менять содержание

- Курсы: `src/content/courses/*.json`
- Педагоги: `src/content/teachers/*.json`
- Фотографии: `src/assets/images/`
- Общие цвета, типографика, интервалы и размеры: `src/styles/tokens.css`

Каждый курс использует один шаблон `CourseLayout`, а блок условий — один компонент `CourseFacts`. Поэтому новые значения не требуют копирования разметки или отдельных CSS-исправлений.

Чтобы добавить курс:

1. Добавьте изображение в `src/assets/images/courses/`.
2. Скопируйте один JSON-файл в `src/content/courses/`, задайте уникальное имя файла и заполните данные.
3. Укажите существующих педагогов в поле `teachers` или сначала создайте новый файл педагога.
4. Выполните `pnpm build`: схема контента остановит сборку, если обязательное поле или ссылка заполнены неверно.

## Архитектура

```text
src/
├── assets/images/       исходные изображения, оптимизируемые Astro
├── components/          переиспользуемые UI-компоненты
├── content/             данные курсов и педагогов
├── layouts/             общая HTML/SEO-обвязка и шаблон курса
├── pages/               маршруты сайта
└── styles/              токены, компоненты и страницы
```

Изображения автоматически получают подходящие размеры и WebP-варианты. `BaseLayout` задаёт canonical URL, Open Graph, Twitter Card и структурированные данные. `robots.txt` и sitemap помогают индексации.

## Деплой

Production-проект Vercel связан с репозиторием `cherars/actingbcn`. Изменения проходят через ветку и pull request; после успешных проверок merge в `main` запускает production deployment. Pull request получает отдельный Preview URL.

Не редактируйте результат сборки `dist/` или файлы непосредственно в Vercel: при следующем деплое они будут заменены содержимым Git-репозитория.
